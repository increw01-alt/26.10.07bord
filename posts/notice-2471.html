[군인대출상품공지] 만20세 이상 남성 현역군인대상(상근예비역,공익,방위산업체 복무자 불가)

원본 등록일 2024.04.18 · 글 번호 2471 · 백업 당시 조회수 3408

T 상품 연동되어 공지 드립니다~

​

​

[조건]

- 대상 : 소득확인 되는 만20세 이상 남성 현역군인대상(상근예비역,공익,방위산업체 복무자 불가)

- 나이 : 만20세 이상

- 한도 : 당사 300~500만원(통합한도 2,000만원)

* 단기복무전문하사 : 500만원 * 대학생 학생증 첨부시 : 500만원

- 금리 : 연 20%(중도상환수수료無)

- 상환방법 : 최대 48개월 만기일시상환

- 금융사 : T

- 환수기준일: 60일 100%, 재대출 90일

​

[특이사항]

- 대부포함 3순위까지 가능(통합한도 2천이내)

- 부대 재직확인전화 없음

- 복무기간 잔여 6개월 ↑

- 원초본상 "ㅇㅇㅇ의 자녀"로 확인시만 진행(손,단독거주불가)

- 대학생 학생증 첨부가능시 한도 500만원 진행

- 폰요금 미납 또는 연체시 대납조건 진행가능(미납금 50만원 이내)

- 나이스7등급 이내 취급

- 본인명의 핸드폰 소지자만 가능

- 기혼자 가능

- 알뜰폰 사용자 가능

- 저축은행 대출 이용자 진행가능(당사대출 포함해서 1000만원 이하인 경우만)

- 복무중인 현 주소지 기재필수

- 대부업 대출 1건 300만원은 심사가능

- LG통신사 이용자 : 유선상 미납 확인불가 납부명세서 첨부必

​

[불가사항]

- 상근예비역,공익,방위산업체 복무자

- 금융권 채무 1500만원 이상 이용자(학자금별도)

- 신용불량자

- 선불폰 사용자

- 여성

- 채무조정자(회생,회복,파산자)

- 사서함 주소 불가

​

* 가상계좌로 이자 납부가 기본이고, 자동이체 희망고객은 은행어플에서 가상계좌 입력 후 설정

(국민은행외 모든 은행은 설정이 가능)

​

[진행절차]

접수(서류첨부후) → 후인증(금융사 문자안내) → 심사 → 여부→ 전자계약서, 녹취→ 송금

->입금완료->10분후 월납부금 및 가상계좌안내->해당 내용으로 주거래은행 자동이체설정->캡쳐본

​

[서류]

동의서, 문진표,경로표시서, 적법수집확인서,신분증,원초본, 병적증명서, 급여통장내역3개월,

* LG유플러스 사용자 : 명세서 必

* 신분증 (팩스본이나 복사본 인정)

*서류발급일 기준 2주이내 / 7일경과시 신용인증 재진행

​

[전산 필수기재항목]

- 부대전화, 주소, 부대명기재필수

- 통화가능시간
