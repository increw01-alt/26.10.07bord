공지사항

[공지사항] 전월세보증금담보대출 (보증금 1500만원 이상부터 가능)

원본 등록일 2023.02.15 · 글 번호 1683 · 백업 당시 조회수 2377

[조건]

- 대상 : 보증금(1500만원),잔존(6개월)/직장인(3개월),사업자(3개월)등 소득증빙 가능자

남성,여성 정상신용자 / 회생,파산중인 고객

- 나이 : 만 25세~만 70세

- 지역 : 전국(제주도가능,도서산간지역불가)

- 한도 : 최대 3,000만원

- 한도기준 : 전세보증금100% / (월세보증금-월세 6개월) 남은잔액100%

- 금리 : 연 20%

- 상환방법 : 만기일시상환

- 대출기간 : 임대만기시까지 / 재계약 연장가능(만기 1개월전 연장확인)

- 금융사 : *플*인 대부

​

[특이사항]

- 임대아파트 가능

- 본인명의 휴대폰 필수

- 전입신고일자와 확정일자 다른 경우도 진행가능

- 개인회생(인가 후)/파산(3개월이상~3년이내) 진행가능(자가일 경우 파산면책 3년 이후 진행가능)

- 9등급 이내가능

- 확정일자, 공인중개사 통한 계약서만 가능

- 1금융권 선순위 보유시 진행가능(후순위만 가능/캐피탈,저축 선순위 사용자 불가)

- 1금융으로 선순위 보유시 임대인법인가능

​

- 임대인 연령대 상관없이 접수가능

​

[불가사항]

- 3개월 이내 연체이력 보유자(해결 시 3개월 이후 접수가능)

- 신용회복자

- 선불폰, 직계가족명의폰 사용자

- 대부 2000만원 초과 사용자

​

[진행절차]

접수(동의서,서류첨부후) → 인증(금융사) → 가승인 → 심사 → 가계약서 작성 → 녹취 → 송금

​

[서류]

* 접수 시 기본서류 : 동의서,대출경로표시서,적법수집확인서, 신분증,임대차 계약서,소득서류

* 추가 보완 서류 : 원초본,등본,소득서류,임대차계약서,인감증명서사본,계약금,잔금입금내역/증빙영수증,월세3개월 입금내역/증빙영수증

​

전체서류 첨부접수시 빠른 진행가능

​

- 소득서류

4대가입직장인(건강보험 득실확인서,납부확인서)

4대미가입직장인(급여거래내역3개월)

사업자(사업자등록증,부가세,소득금액증명원)

​

개인회생 : 사건번호/법원/환급계좌 기재 必

파산 : 사건번호/법원 기재 必
